The desktop

The launcher

One box for opening apps and finding almost anything else: a setting, a window, a file, a sum, an emoji. Open it, start typing, and press Enter.

Opening it

  • Tap Super on its own.
  • Press Super + Space.
  • Click Apps on the menu bar, or the Apps button at the start of the dock.

Press Esc to close it. Changing workspace closes it too.

Before you type

Your apps are listed with the ones you opened most recently at the top, ready to pick.

What you can find

Apps

Type part of an app's name. The search is forgiving: initials and small slips still find what you meant, so "vsc" finds Visual Studio Code and "fierfox" finds Firefox. Apps you open often rise up the list.

Settings

Every setting in Slate's Settings can be found from here. Type what you want to change, like "dock size" or "night light", and pick it to open Settings right at it.

Open windows

Type part of a window's title, or its app's name, to go to it, whichever workspace it's on.

App actions

What apps offer besides opening, like a browser's New Private Window, show up when you type the app's name or the action's.

Quick toggles

Wi-Fi, Bluetooth, Airplane Mode, Private Mode, Do Not Disturb, night light and game mode can be switched straight from the results. Type "wifi" or "dnd" and press Enter.

Files and folders

Files you've opened recently, and folders in your home by name.

Sums and conversions

Type a sum and the answer appears as you type. Conversions work the same way: "5 km in miles", "72 f to c", "today + 30 days". Press Enter to copy the answer.

Emoji

Start with a colon to find an emoji by name, like :smile. Enter copies it. There's also an emoji picker of its own on Super + ..

Commands

Start with > to run a command. You can run it in a terminal, which stays open afterwards so you can read what it said, or on its own with no terminal.

The web

The last result searches the web for what you typed, in the search engine you choose: DuckDuckGo (to start with), Google, Bing, Brave Search, Startpage or Ecosia.

Each kind of result can be switched off in  Settings → Launcher → What it finds, if you'd rather keep the list to apps.

Keyboard and mouse

KeysWhat they do
↑ ↓, Tab Shift + TabMove through the results.
Page Up Page DownMove a page at a time.
EnterOpen what's selected.
Super + EnterOpen the selected app on a new workspace at the end.
← → (in the grid, Ctrl + ← →)Open the selected app on a new workspace just to the left or right of this one.
EscClose the launcher.

With the mouse, just click a result. With Wrap around on, the arrow keys go from the last result back to the first, and from the first to the last.

List or grid

Choose a List or a Grid in  Settings → Launcher → Layout.

  • List shows each app with a short description beneath its name (or without, if you switch Show descriptions off).
  • Grid shows bigger icons, with the selected app's name along the bottom. Set how many Columns and Rows it has; the icons get smaller the more columns there are, and you scroll for more rows. In the grid, the arrow keys move between apps.

Either way, the launcher shrinks smoothly to fit the results as you type, and the search box stays where it is.
