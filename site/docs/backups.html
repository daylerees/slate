Your computer

Backups

Copies of your files on another drive, encrypted, with past versions to go back to:  Settings → Backups. Once it's set up, Slate backs up by itself, quietly.

Setting up

Plug in a drive and choose it under Back up to, or type a folder (a network folder that's mounted works too), then press Set up. Slate makes an encrypted backup there with restic, and a key to open it, kept in your keyring. The first backup starts straight away.



Keep a copy of Your backup key somewhere safe (Show, then Copy). Without it, your backups can't be opened on another computer. Backups need restic (the restic package); without it, the page says so.

What and when

SettingWhat it does
What to back upYour home folder (to start with): everything in it except caches, the Waste Basket and installed apps. Or just Documents, pictures, music and videos.
How oftenEvery day (to start with), Every week, or Only when I ask. Backups run quietly in the background, never in game mode. When the drive's unplugged, Slate catches up once it's back, and after a week without a backup it reminds you once.

Back up now runs one straight away. Slate only sends a notification if a backup didn't finish.

Restoring

Under Restore, press Look, choose a backup by its date, and open folders to find what you want. Restore brings a file or folder back into a new folder in your home, Restored from backup, beside your files and never over them, and opens it.
