Apps and tools

Default and startup apps

Tell Slate which apps you like for the everyday things, and which you'd like waiting for you each time you log in.

Default apps

In  Settings → Default Apps, choose an app for each of these. Slate's shortcuts and menus use them, and so do links and files you open:

AppUsed for
TerminalSuper + Return.
Web browserLinks you open.
FilesSuper + E, and folders you open.
Text editorSuper + T, and text files you open.
CalculatorSuper + C, and your keyboard's calculator key.

Each list offers the apps you have installed that can do the job. Anything you leave unchosen uses Slate's own choice, or the one set in ~/.config/slate/hypr/variables.lua if you've set one there (Your own config).

Startup apps

In  Settings → Startup Apps, Add an app and pick one from the list. It opens each time you log in. Your startup apps are listed under At login, and you can remove one with the button beside it; Slate asks first, and you can always add it again.

If you restart with your apps reopening, each startup app opens on a workspace of its own, so it doesn't crowd the windows coming back.



Anything started from your own ~/.config/slate/hypr/autostart.lua still opens too, alongside the apps listed here.

Opening apps

To find and open any app, use the launcher (Super on its own, or Super + Space), or keep your favourites on the dock.
