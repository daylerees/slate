Reference

Keyboard shortcuts

Slate's shortcuts are built around the Super key: tap it for apps, hold it with Tab to switch windows, and use the arrows for workspaces. If you already know Hyprland's keys, you can keep them instead.

Seeing and searching them

 Settings → Shortcuts lists every shortcut for the set you're using, grouped, with a search box at the top. It includes shortcuts you add yourself, as long as you give them a description (see Adding your own).

Super is the key with your operating system's logo on it: the Windows key on most keyboards, or Command (⌘) on a Mac one.

Choosing a set

The Shortcut set at the top of Settings → Shortcuts has three choices. Changing it applies straight away.

  • Slate (the default): everything on this page, below.
  • Hyprland Defaults: Hyprland's own shortcuts, as in its example config. See Hyprland's defaults.
  • Hyprland + Slate Extras: Hyprland's defaults, with Slate's shortcuts added on the keys they leave free.

The hardware keys (volume, brightness, media) and asking Nova work the same in all three.

Hardware keys

These work in every set, and even while the screen is locked:

  • Volume up, down and mute, and microphone mute, with an on-screen indicator.
  • Brightness and keyboard backlight up and down.
  • Media: play or pause, next and previous, for whatever's playing.
  • The calculator key opens your calculator.

Slate's extras

Hyprland + Slate Extras adds Slate's shortcuts wherever Hyprland's leave the keys free: tapping Super, Super + Tab, Settings, the control centre, notifications, the lock, emoji, screenshots, zoom and the rest. Three of Slate's move to new keys, because Hyprland already uses theirs:

KeysWhat they do
Super + Shift + VClipboard history
Super + Shift + PPick a colour from the screen
Super + Ctrl + ↓Workspace overview

Settings → Shortcuts always shows exactly what's in use, so it's the best place to check.

Adding your own

Your own shortcuts go in ~/.config/slate/hypr/binds.lua. It's loaded after Slate's, so a shortcut there replaces Slate's on the same keys, and saving the file applies it straight away. If something in it is wrong, a notification says what.

hl.bind("SUPER + B", hl.dsp.exec_cmd("firefox"), { description = "Apps: Firefox" })
hl.unbind("SUPER + J")   -- remove one of Slate's

A description written as "Group: what it does" lists it in Settings → Shortcuts under that group. Any of Slate's actions can go on a key too, through the slate command. More in Your own config.
