Reference

The slate command

Everything Slate does is reachable from a terminal through one command, slate. It's handy for restarting Slate, reading its log, and putting any of Slate's actions on a key or in a script.

The installer puts slate in ~/.local/bin. If your terminal says it can't find it, add that folder to your PATH, or use the full path, ~/.config/slate/bin/slate.

Commands

CommandWhat it does
slateStarts Slate, if it isn't running
slate restartRestarts Slate. The screen fades to "Reloading Slate" and back, and your apps and windows stay open
slate restart --fullStops Slate completely and starts it again, rather than reloading it in place
slate restart --no-coverRestarts without the "Reloading Slate" screen
slate stopStops Slate
slate logFollows Slate's log as it's written
slate logsSaves recent logs and system details to a file in Downloads, for a bug report
slate ipc call <target> <function> [args]Asks the running Slate to do something (below)
slate ipc showLists everything that can be called
slate dirPrints where Slate is installed
slate mcpSlate's MCP server, for an AI agent to start (Slate for AI agents)
slate build-hyprbarsBuilds Hyprbars, the optional title-bar plugin (again after Hyprland updates; --status says where it stands)
slate --helpShows this list

Talking to Slate

slate ipc call runs one of Slate's actions in the running Slate: the same ones its own shortcuts use. Put them on a key in ~/.config/slate/hypr/binds.lua (see Your own config) or use them in your scripts. slate ipc show lists every target and what each takes.

Settings and the shell

slate ipc call settings toggle                         # open or close Settings
slate ipc call settings page wallpaper                 # open Settings on a page
slate ipc call settings find appearance "Interface size"   # open a page at one setting
slate ipc call settings search "dock"                 # search Settings, as typing in its search box
slate ipc call config get dockAutoHide                 # read a setting
slate ipc call config set glass true                   # change a setting
slate ipc call welcome open                            # the Welcome window
slate ipc call shell reload                            # reload Slate in place

Page names are the ones Settings uses inside: general, appearance, wallpaper, icons, displays, input, sound, power, windows, workspaces, notifications, wifi (Network), bluetooth, bar (Menu Bar), dock, shortcuts, updates, debug, about and so on. Setting names are the keys in ~/.config/slate/settings.json.

The desktop

slate ipc call launcher toggle
slate ipc call launcher search "2*pi"
slate ipc call bar panel control       # control, notifications, volume, wifi, bluetooth, battery, calendar, session…
slate ipc call overview toggle
slate ipc call picker toggle clipboard  # or emoji
slate ipc call wallpaper set ~/Pictures/hills.jpg
slate ipc call wallpaper next
slate ipc call spaces restore Coding
slate ipc call spaces list

Sound, light and quiet

slate ipc call osd volume up          # up, down or mute, with the on-screen indicator
slate ipc call osd volumeSet 40
slate ipc call osd mic mute
slate ipc call osd brightness down
slate ipc call media toggle           # play or pause; next, previous
slate ipc call notifications dnd true # Do Not Disturb on
slate ipc call nightlight toggle
slate ipc call airplane toggle
slate ipc call private toggle         # Private Mode

Locking, power and updates

slate ipc call lock lock
slate ipc call screensaver start
slate ipc call power confirm logout   # asks first, as the power menu does
slate ipc call updates check
slate ipc call assistant ask "turn on glass"   # Nova, once it's switched on


These talk to the Slate that's running, so they need it started. If it isn't, slate starts it.

Where things live

WhatWhere
Slate itself, and your settings (settings.json)~/.config/slate/
Your own Hyprland tweaks and QML~/.config/slate/hypr/ and ~/.config/slate/user/
The version before an update~/.config/slate.previous/
Saved state: dock pins, launcher counts, notification history~/.local/state/slate/
Your saved Spaces, and factory reset backups~/.local/share/slate/
Caches, such as app icon tiles~/.cache/slate/
The log~/.cache/slate.log

Your usual ~/.config/hypr isn't used by the Slate session; it stays with your other Hyprland session.
