Getting started

Installing Slate

Slate installs as a session of its own, beside the desktop you have now. One command does it, and nothing about your existing desktop changes, so you can try it and switch back at login.

What you need

  • Hyprland 0.57 or newer. Slate's session uses Hyprland's Lua config, which older versions don't understand.
  • Quickshell 0.3 or newer, the toolkit Slate is written in.
  • A login service: systemd, which most distros use, or elogind on systems without it. It's what lets Slate suspend, restart and shut down, lock before sleep, and show password prompts.
  • PipeWire, NetworkManager, polkit and a few other packages. The installer installs these for you.

If your distro's Hyprland or Quickshell is too old, the installer says so and points you to the notes for your distro below.

Installing

git clone https://github.com/daylerees/slate.git && cd slate
./install.sh

Run it as your normal user, not with sudo. It shows you what it's going to do and asks before each change to your system, and asks for your password when it installs packages or adds the login entry.

When it's finished, log out, choose Slate on the login screen, and log in.

What the installer does

  1. Packages. Installs your distro's list (you see it first). If you have no terminal or file manager, it offers kitty and Nautilus; ones you already have are used instead. It also offers to switch on Bluetooth and NetworkManager if they're off.
  2. Checks that Hyprland and Quickshell are new enough.
  3. Fonts, icons and pointers. Geist and Geist Mono come with Slate, and are installed for your other apps too. Papirus becomes your icon theme unless you've picked your own, and Slate's pointers are made available to the session.
  4. Slate itself, copied to ~/.config/slate, with the slate command in ~/.local/bin. An existing copy is kept as ~/.config/slate.previous, and your settings and own files come along.
  5. The login entry, so login screens list Slate. This works with GDM, SDDM, LightDM and greetd.

Options

OptionWhat it does
--yesDoesn't ask, and answers yes to everything
--login-screenAlso switches your login screen to Slate's own. Optional: read Slate's own login screen first
--no-depsSkips installing packages, for when you've installed them yourself
--linkLinks ~/.config/slate to the folder instead of copying it, for working on Slate
--uninstallRemoves Slate (see Removing Slate)

./install.sh --help lists them too.

Your distro

Arch, CachyOS, EndeavourOS and Manjaro

Just ./install.sh: everything is in the official repositories. If you have paru or yay, it can also add swash (the screenshot editor) from the AUR.

Debian testing and sid

Just ./install.sh. Debian 13 "trixie" only has Hyprland up to 0.55, so you'll need testing or sid.

Ubuntu 26.04 and newer

./install.sh adds a PPA for a current Hyprland (ppa:cppiber/hyprland), then offers to build Quickshell from source, since Ubuntu doesn't package 0.3 yet. That takes five to ten minutes.



Quickshell built from source needs building again after Ubuntu updates Qt, or Slate won't start. Run packaging/build-quickshell.sh from the Slate folder when that happens.

Fedora 44 and newer

./install.sh enables two COPRs for you: sdegler/hyprland and errornointernet/quickshell, since Fedora's own Quickshell is too old.

openSUSE Tumbleweed

./install.sh. Hyprland comes from the official repositories, and the installer offers to build Quickshell from source, as on Ubuntu (so the same note about Qt updates applies).

NixOS

Add the contents of packaging/nixos.nix to your configuration (it needs nixos-unstable for Hyprland 0.57), run sudo nixos-rebuild switch, then ./install.sh --no-deps. Since Nix manages /etc and /usr/share, you add the Slate session with services.displayManager.sessionPackages, and greetd with services.greetd, in your configuration.

Artix, Void and Gentoo

Slate also runs without systemd, as long as elogind is installed and running. This support is new and hasn't yet been tried on real installs, so we'd love to hear how it goes.

  • Artix: switch on the world and galaxy repositories, then run ./install.sh.
  • Void: Hyprland needs a third-party repository with 0.57 or newer; Quickshell is in Void's own. Then ./install.sh.
  • Gentoo: ./install.sh shows the package list and stops, so you can emerge them your way (Hyprland from hyproverlay, Quickshell from GURU), then run ./install.sh --no-deps.

Without systemd, Slate shows you the command to switch a service on rather than doing it itself, and the session starts sound for you. The full notes are in INSTALL.md.

Other distros

Install Hyprland 0.57 or newer, Quickshell 0.3 or newer and the packages listed in ARCHITECTURE.md, then run ./install.sh --no-deps.

Not yet possible: Debian 13, Ubuntu 24.04 and 25.10, Fedora 43, openSUSE Leap, Alpine, Chimera and Devuan, which don't have Hyprland 0.57 yet (or have a Qt too old for Quickshell).

Logging in to Slate

Log out, and on your login screen pick Slate from the list of sessions (often behind a small gear or a menu), then log in as usual. The Welcome window opens the first time: Your first login walks you through it.

To go back to your old desktop, log out and pick it at the login screen. Nothing there has changed, and you can switch between the two whenever you like.



If Slate isn't in the list, run sudo ~/.config/slate/bin/slate-session-install. Some login screens only look for new sessions after a restart.

Slate's own login screen

Slate has a matching login screen too, with your wallpaper and picture. It's optional, and nothing changes your login screen unless you choose to install it, from  Settings → Security → Slate login screen (or with ./install.sh --login-screen). Settings explains what's involved before it does anything.



It replaces your system's login screen, so a broken one could stop you logging in, and it needs updating with your password when Slate, Hyprland, Quickshell or greetd change. Slate guards against this: each update is tested before it's installed, and if it still fails at boot, the last version that worked takes over, then a basic emergency login. You can switch back from the same place in Settings at any time.

Removing Slate

./install.sh --uninstall

This takes Slate off the login screen, puts your previous login screen back if you installed Slate's, and moves ~/.config/slate aside to slate.removed-<date> rather than deleting it. Packages are left installed, since other apps may use them. Slate's saved state in ~/.local/state/slate and ~/.cache/slate can be deleted by hand if you'd like.
