Windows and workspaces

Windows

Out of the box, Slate tiles your windows side by side so nothing hides behind anything else. If you'd rather have a traditional desktop, or something in between, each workspace can arrange its windows its own way.

Window modes

A window mode decides how windows are laid out on a workspace. There are six:

ModeWhat it does
TilingThe default. Windows share the screen side by side, each new one splitting the space. Super + J splits the other way.
Side StackOne main window on the left, the rest stacked beside it. Super + J makes the window you're in the main one.
ScrollingWindows sit in columns on a strip that scrolls sideways as you move between them. Super + J changes a column's width.
StackingOne window at a time, filling the screen, with the others waiting behind it. Super + J, or Super + Alt + ← / →, moves between them.
SoloEvery window fills a workspace of its own: a new one opens on the next free workspace. You move between windows as you move between workspaces. Dialogs stay with their app.
FloatingWindows open floating and centred, like a traditional desktop, with a title bar to drag them by.

In any mode, Super + Alt + Space floats the window you're in, or tiles it again.

A mode for each workspace

The button beside the workspace dots on the menu bar shows the workspace's mode. Click it to choose another for just that workspace, or Default to follow the default again. The same panel has a pencil for naming the workspace (see Workspaces).

The default

Every workspace without a mode of its own uses  Settings → Windows → Default window mode. If you change it while windows are open in another mode, Slate asks first: Tidy up moves every workspace to the new mode now, or leave them as they are and the new default is used for new workspaces only. Your windows stay open either way.



Spaces remember each workspace's mode, so a space you bring back is laid out the way you saved it.

Moving and resizing

  • Move a window: hold Super and drag it, or press Super + Shift and an arrow key.
  • Resize a window: hold Super and drag with the right mouse button, or press Super + R and use the arrow keys.
  • Go to the window beside: Super + Alt and an arrow key.
  • Maximise: Super + D. Full screen: Super + F.
  • Close: Super + Q. If an app stops responding, Super + Esc and a click on its window force-quits it.

These are Slate's own shortcuts. If you've chosen Hyprland's set instead, see Keyboard shortcuts.

Floating windows

Floating windows have a title bar with the window's title and app icon, a close button and a maximise button. Drag the title bar to move the window, and double-click it to maximise; click maximise again to put it back.  Settings → Windows → Title bar buttons puts the buttons on the left or the right.

Drop a floating window with its top above or under the menu bar and it slides back down below the bar, title bar and all, so you can always grab it again. Sideways, a window can hang off the edge as much as you like.

Title bars

 Settings → Windows → Title bars has two kinds:

  • Slate Bars, the default: Slate draws a title bar on the floating window in front, with nothing to install or rebuild. It wraps round the window's rounded corners, fades out while the window moves or resizes, and its top corners resize the window. With Slate Bars, a window takes focus when you click it.
  • Hyprbars, optional: title bars from a Hyprland plugin, on every floating window. Choose it and Slate explains what's involved, builds it on your computer in the background, and switches once it's ready.


Hyprbars has to be rebuilt after every Hyprland update. Until it is, Slate quietly uses Slate Bars instead, then asks whether to rebuild, offers a reload when it's done, and asks whether to switch back. The Hyprbars row in Settings → Windows has Rebuild, Retry, Reload and Remove for when you want to do it yourself. Reloading keeps your windows open.

Gaps, borders and dimming

In  Settings → Windows → Layout & borders:

SettingWhat it does
Window bordersA border in your accent colour round each window when a workspace has more than one. 3 px to start with; 0 turns them off.
Window spacingThe gap between windows (the screen's edges get a little more). 6 px to start with.
Space around a lone windowPadding round a window that's alone on its workspace, so it keeps its rounded corners. 0, the default, lets it fill the screen up to the bar.
Dim inactive windowsDarkens the windows you're not using, so the one you are stands out. 50% to start with. Settings itself never dims, so you can watch a change take effect.

Floating windows cast a shadow; tiled ones don't, so it doesn't read as a second outline beside the border. The shadow follows your shadow settings.

Focus

Focus follows the pointer, in Settings → Windows, lets windows take the keyboard as the pointer moves over them. Off, you click a window to use it (scrolling still reaches the window under the pointer). While floating windows use Slate Bars, windows always take focus with a click, so the switch is hidden.

Windows that look after themselves

  • Picture-in-picture videos float and stay on top.
  • Games from Steam and gamescope go full screen on a workspace of their own.
  • Terminals step aside for the apps they open.
  • Dialogs, such as file pickers and save boxes, float in the middle of the screen and stay with their app.
  • Floating windows remember their size, and one that would open bigger than the screen, or hang off it, is brought back in.
