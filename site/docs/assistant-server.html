Slate for AI agents

Slate has an MCP server, slate mcp, that lets an AI agent you already use (Claude Code, Codex, or any that speaks the Model Context Protocol) answer questions about your desktop and do things on it. It's off until you switch it on, and Slate asks you before anything that can't be undone.

"Turn on glass." "Put Firefox on workspace 2." "Which window is on workspace 3?" "Where do I change the font?" Nova is Slate's own way to ask, through the same tools; this page is about using them from an agent of your own.

Before you switch it on

These are best efforts, and it's fairer to say so than to promise. Using an assistant with Slate is your choice, and what it does on your behalf is your responsibility.

  • What leaves your computer. Whatever a tool answers (your settings, your open windows and their titles, the names of your workspaces, Spaces, apps and wallpapers) goes to the service behind your agent, under your own account with them. Slate itself sends nothing anywhere.
  • What it can do. Change settings, move windows and open apps without asking. Slate asks you before anything that can't be undone.
  • What can go wrong. Assistants make mistakes, and can be misled by text they read, like a web page's title. Slate does its best to limit the harm, but it can't promise what an assistant will do.

Switching it on

Go to  Settings → Assistant and switch on Let assistants use Slate. Slate shows you the points above and asks; only Switch on switches it on. Read the risks again shows them at any time, with a button to switch off. If a later version of Slate changes what the risks are, assistants pause until you've read the new ones.

While it's off, every tool simply answers that assistants aren't switched on, and does nothing.

Adding it to an agent

An agent starts the server itself when it needs it; you never run it by hand.

# Claude Code
claude mcp add slate -- ~/.config/slate/bin/slate mcp

# Codex
codex mcp add slate -- ~/.config/slate/bin/slate mcp

Most other agents take a block like this in their settings, with the whole path in place of ~:

{ "mcpServers": { "slate": { "command": "/home/you/.config/slate/bin/slate", "args": ["mcp"] } } }

Settings → Assistant has these lines under Use Slate from other apps, each with a Copy button, and slate mcp --help prints them. To take it away again, remove it the same way (claude mcp remove slate).

What it can do

Looking

These only read, and never ask: Slate's status (the theme, volume, battery, the focused window and so on), finding and reading settings, your open windows, workspaces, saved Spaces, installed apps, wallpapers, what's playing, and your recent notifications (only while you allow it, below).

Changing

These can be undone, so they happen straight away, unless you've asked Slate to ask about every change:

  • Changing a setting, or opening Settings at one for you to look at
  • Applying one of Slate's looks, opening a panel from the menu bar
  • Arranging the menu bar: what's on it and where, how each container collapses, what leaves first when it's short of room and what always stays, or Slate's own arrangement again
  • Opening an installed app (only an app: no file, address or command)
  • Going to, moving, floating, tiling, maximising or full-screening a window
  • Switching workspace, changing a workspace's window mode, naming one
  • Opening or saving a Space (saving over one asks first)
  • Changing the wallpaper to one of yours or Slate's
  • Volume, brightness, play and pause, Do Not Disturb
  • Taking a screenshot for you, as Print does. The assistant is only told it's done: it never gets the picture, or where it was saved
  • Locking the screen, starting the screensaver

Always asking

These can't be undone or could lose work, so Slate asks you every time, in its own confirmation window, and no setting turns the question off: closing a window, deleting a Space, and logging out, restarting, shutting down or sleeping.

What there's no tool for

Running a command, opening a file or web address, typing or clicking for you, reading the clipboard, answering a password prompt, unlocking the screen, or installing or updating anything.

What it refuses

Some settings are yours alone, and Slate refuses to let an assistant change them, saying where you can change each yourself:

  • What assistants may do and see (everything on Settings → Assistant)
  • Anything that holds a command or reaches outside Slate: default apps, startup apps, launcher commands, clipboard history, log detail
  • Folders, the lock settings, keyboard layouts and the shortcut set, your location, the title bar style and the main display
  • Private Mode, which only you can turn on or off

While the screen is locked, every tool is refused.

How Slate keeps it in bounds

  • Slate decides, not the agent. Every call goes through Slate's own checks first, whichever agent made it.
  • The questions are Slate's. They use fixed sentences with checked names, with Cancel picked first. The assistant can't write them.
  • A no is a no. After a no, Slate doesn't ask about that again for ten minutes, and asks at most five questions in any ten minutes. A question nobody answers goes away after 45 seconds, and nothing happens. In game mode, questions are declined without interrupting you.
  • Only from the lists. A window that's open, an app that's installed, a wallpaper from your folder, a Space that's saved. Nothing an assistant makes up reaches your desktop.
  • Words only. Slate's tools never give a picture of the screen, a window's contents, a file, the clipboard or anything you've typed. Your location is never given.
  • Text from other apps is cleaned, and the agent is told it's information, never instructions. This helps, but isn't something to rely on.
  • Sixty calls a minute at most, so a looping assistant is told to slow down.


Slate can only answer for its own tools. An agent with a terminal of its own can do whatever a terminal can, with or without Slate's server, including running slate ipc and skipping Slate's questions. With Claude Code, Nova switches the agent's own tools off for its prompts; an agent you add yourself keeps whatever you've given it.

Your permissions

On  Settings → Assistant, which an assistant can't change:

SettingTo start withWhat it does
Ask before changing anythingOffSlate asks before every change, not only the ones that can't be undone
Window titlesOnOff: assistants get app names only, never window titles, which can name documents and web pages
NotificationsOffOn: assistants can read your recent notifications

Activity

Everything assistants did is listed under Activity: the time, which agent, what it asked for, and how it ended (done, declined, no answer, refused or failed). It holds tool calls only, never what you typed or what the agent answered, and stays on your computer. Clear empties it.

Private Mode

Turning on Private Mode (a quick switch in the control centre) turns assistants off too: every tool says so and does nothing, until you turn it off again. An assistant can't change Private Mode itself.
