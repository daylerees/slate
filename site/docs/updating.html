Getting started

Updates

Slate looks for a new version once a day and lets you know with a notification. Updating takes one click, keeps your settings and your own tweaks, and keeps the version you had so you can go back.

Knowing there's a new version

When a new release is out, a notification tells you. You'll find everything about it in  Settings → Updates, which you can also reach from the control centre's right-click menu.

The Version section shows the version you have, the latest one, and when Slate last checked. Check now looks straight away. If you'd rather Slate didn't look by itself, switch off Check for updates.

Updating

When there's a new version, Settings → Updates shows What's new in it, with a link to its release page. Choose Update now: Slate downloads it, puts it in place and restarts on the new version. Your apps and windows stay open.

Your settings and your own tweaks always come along: settings.json, hypr/ and user/ in ~/.config/slate.

  • If you've changed Slate's own files by hand (anything outside those three), Settings lists them before updating, since the update replaces them. Your versions stay in the copy kept below, and you'll be asked to click a second time.
  • If the new version needs new packages, or changes the login session, it asks for your password and installs them as it updates. If you cancel, or it needs a newer Hyprland or Quickshell than your distro has, it stops before changing anything and tells you what to do.
  • If an update doesn't finish, Settings says so, with Show log and Try again. Nothing is lost.

Each release's notes are also in the changelog.

Going back

Slate keeps the version you had before, in ~/.config/slate.previous. Under Previous version in Settings → Updates, Go back (and a second click to confirm) switches to it.

Your settings and tweaks stay just as they are now, and the version you leave is kept in its place, so you can switch back again the same way.

Missing packages

About half a minute after it starts, Slate checks that everything it needs is installed. If something's missing (a package removed since, say), a notification offers to install it, with your password. It asks once for each set of changes, and Later waits a week. To see what it would do, run ~/.config/slate/bin/slate-system --check.

The login screen

If you've installed Slate's own login screen, it's updated separately, because it runs from a system folder before you log in. When its design changes, Slate asks with a Login screen out of date notification; Update asks for your password. Until then you'll see the previous version at login, which is quite safe. More in Locking and login.

From a copy of the code

If you installed from a clone of the repository and would rather update that way:

cd slate && git pull
./install.sh --no-deps

Your settings are kept, just as with an update from Settings.
