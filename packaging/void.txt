# Slate packages for Void Linux (runit, glibc or musl)
# One per line. "?" = optional (installed if available)
#
# Hyprland isn't in Void's own repositories: add a third-party repository that has Hyprland
# 0.57 or newer first (see docs/INSTALL.md). The names below are Void's as far as we know
# them; the installer installs one at a time and tells you any it couldn't find, so a name
# that has changed doesn't stop the rest.

# Compositor and shell
hyprland
xdg-desktop-portal-hyprland   # Hyprland's screen sharing and recording portal (browsers, OBS, Discord; Private Mode switches it off)
quickshell
qt6-declarative

# Scripts and images
python3
python3-Pillow
python3-gobject     # the tray's register, apart from Slate (scripts/tray-watcher.py)
python3-numpy
librsvg
ImageMagick
wl-clipboard

pipewire
wireplumber
?qt6-multimedia     # click sound, and sounds without a delay
NetworkManager
bluez
upower
polkit
pam
elogind             # the login service: suspend, restart, lock before sleep, password prompts
util-linux
diffutils           # cmp: is the installed copy (Slate, the login screen) up to date
dbus
glib
gvfs                # the Waste Basket's trash: location, so emptying it works (gio trash --empty)
procps-ng
libnotify
fontconfig
curl
xdg-utils
